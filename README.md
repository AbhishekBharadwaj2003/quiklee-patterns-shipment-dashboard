# Quiklee Patterns Shipment Analytics Dashboard

**Internship Task 2** — a Streamlit application for shipment analytics across Freely, Kotart, and BigBearFarms.

Planned features include brand-specific KPIs, daily shipment trends, courier performance, state-wise courier comparisons, dataset upload and historical snapshots, executive report exports, and Ask Quiklee.

## Deployment

This is a Python/Streamlit app intended for Streamlit Community Cloud. Configure the deployed app's entrypoint to the project's Streamlit entrypoint (for example, `app.py`) after the complete application files are uploaded.

## Data and privacy

Do not commit production shipment data, customer-identifying data, credentials, secrets, or a local SQLite database to this repository. Add application files and any sanitized/demo datasets intentionally.

This repository is separate from Task 1: `quiklee-shipment-analytics`.
